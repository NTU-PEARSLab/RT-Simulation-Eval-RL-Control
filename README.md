# RT-Simulation-Eval-RL-Control
Resources for "Using Real-Time Simulation to Evaluate a Reinforcement Learning Control Algorithm in Photovoltaic Inverters with Battery Storage " by Dong-Heng Tsai, Darsana Deo, Yu-Quan Chen, F. Selin Bagci, Yu-Kai Liao, Katherine A. Kim, Iris Hui-Ru Jiang, and Jonghoon Kim, submitted to IEEE Access

# Real-Time Simulation PLECS RTBox Files

These are the files used to run the real-time simulation on two RTBox using PLECS software. One RTBox 1 and one RTBox 2 were used. Please refer to Fig. 12 in the paper for the conceptual diagram.

Zip File: PLECS_RTBox_Files_20260909.zip

Contains: 
Folder: Apr12

Folder: Jan4

Folder: Jun14

Folder: Jun24

Folder: May14

Each folder for date (labeled below as ABCD) contains: 

> RTbox1_Inverter_ABCD.plecs

> RTbox2_PV_ABCD.plecs

> tracefile (containing supporting PLECS files)

# Matlab Data and Figure Files

These are the files that include the data from the real-time RTBox simulations, which plot different aspects of the data, shown as Figures 13-15 in the paper.

Zip File: MATLAB_Figure_13_Files_20260909.zip

Contains: Matlab (.m) file and PV Power data for each day (.csv)

> PVPowerCurveHILtesting.m (open and run this file)

Zip File: MATLAB_Figure_14_Files_20260909.zip

Contains: Matlab (.m) file and Battery Power and Grid Power data for each day (.csv)

> GridandBatteryPowerHiltesting.m (open and run this file)

Zip File: MATLAB_Figure_15_Files_20260909.zip

Contains: Matlab (.m) file, data for each day (.csv), and Matlab data file with PV data (.mat)

> RLAlgMI_GridLevelData_plots.m (open and run this file)
